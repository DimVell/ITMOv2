Notify Mini — задание для доработки макета в Figma с помощью AI

Цель: получить отдельный редактируемый макет для практики 8 и сопоставить его
с уже работающим React-интерфейсом. Это доработка существующего решения,
а не утверждение о том, что первый вариант приложения был создан по Figma.

Пользователь: владелец небольшого проекта, который ведёт список подписчиков.
Сценарий: открыть список → ввести имя → отправить → увидеть подписчика в списке.

Визуальные ориентиры:
- evidence/real-api.png — работающий интерфейс на широком экране.
- evidence/mobile.png — мобильная компоновка.
- evidence/empty.png, input.png, loading.png, success.png, error.png — состояния.
- lab/design/prototype.html — первоначальный AI-прототип в HTML.
Пути указаны относительно practices/practice_08.

Сделать фреймы для desktop 1440px и mobile 375px.
Сохранить: белую верхнюю панель notify mini, крупный заголовок,
счётчик подписчиков, карточку добавления и карточку списка.
На мобильном экране карточки идут вертикально.

Токены: основной цвет #246b48, основной текст #17261f, вторичный #63716a,
фон #f4f6f5, белые карточки, границы #e4eae6, ошибка #b52f38.
Шрифт: Inter или системный sans-serif. Основной текст 16px, кнопки около 15px.
Радиусы карточек 14px, кнопок 10px. Общее расстояние между карточками 26px.

Компоненты реализации — Material UI: Button, TextField, Card, Alert,
Avatar, Chip, List, Skeleton, CircularProgress, Typography.
Использовать повторно компоненты и общие токены, а не несвязанные элементы.

Показать состояния:
1. Пустой список и форма без ввода.
2. Введено «Анна Иванова».
3. Выполняется запрос: кнопка «Добавляем…», поле и кнопка заблокированы.
4. Успех: имя в списке, счётчик обновлён, поле очищено, сообщение об успехе.
5. Ошибка сохранения: введённое имя сохранено, есть понятное сообщение и повтор.
6. Валидация пустого имени и имени длиннее 40 символов.

Функциональные ограничения: API работает только с именем подписчика.
Не добавлять вымышленные email, аватары-фотографии, даты подписки, рассылки,
удаление, авторизацию или другие неподключённые функции.

Доступность: подпись поля, видимый клавиатурный фокус, читаемый контраст,
полный сценарий с клавиатуры, отсутствие горизонтального скролла на мобильном.

Для сдачи сохранить ссылку на Figma и экспорт. Зафиксировать, что предложил AI,
какие изменения сделаны после просмотра, и при необходимости согласованно
обновить прототип и приложение. Не выдавать исходный HTML за макет из Figma.
