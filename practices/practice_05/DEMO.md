# Короткое демо

## Автоматический сценарий (около 5 секунд)

```bash
make demo
```

Сценарий запускает настоящий HTTP-server на свободном локальном порту и показывает:

1. адрес UI;
2. новое имя → `201`, `created=true`;
3. то же имя в другом регистре → `200`, `created=false`;
4. пустое имя → `400`, `invalid_name`;
5. итоговый список с одной записью.

## Демо UI на защите (до минуты)

```bash
make run
```

1. Открыть `http://127.0.0.1:8000` — видны пустое состояние и счётчик `0`.
2. Добавить `Анна` — видны сообщение об успехе, строка списка и счётчик `1`.
3. Добавить `  АННА  ` — виден нейтральный ответ о дубликате, счётчик остаётся `1`.
4. Отправить пробелы — UI показывает backend-ошибку и остаётся работоспособным.
5. Перезапустить server — `Анна` загружается из `.data/subscribers.json`.

После демонстрации локальный `.data/subscribers.json` можно удалить; он не входит в сдачу.
