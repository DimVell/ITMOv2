# Согласование двух команд

Дата решения: 2026-10-29. Framework: Kiro. Согласование выполнено до написания кода фичи.

| Вопрос | UI до | Логика до | Принятое решение |
|---|---|---|---|
| Статус создания | всегда `200` | `201` новое, `200` повтор | вариант логики: статусы различают результат |
| Тело ответа | плоское имя | subscriber + created | вариант логики: UI не угадывает дубликат |
| Дубликат | ошибка | идемпотентный успех | идемпотентный успех и нейтральное сообщение UI |
| Нормализация | не определена | пробелы + case-insensitive | выполняется только backend, UI показывает сохранённое имя |
| Длина | не определена | 40 символов | 40; HTML `maxlength` помогает, API остаётся источником истины |
| Ошибка | произвольный текст | code + message | стабильный объект `error`; UI показывает `message` |

## Итог

Общий контракт зафиксирован в [`common-contract.md`](common-contract.md). После решения обе
команды обновили Kiro requirements/design/tasks. Реализацию разрешено начинать только после
этого обновления.
