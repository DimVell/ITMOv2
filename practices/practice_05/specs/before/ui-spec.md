# Команда 1 — UI spec до согласования

## Намерение

На странице есть поле имени, кнопка добавления, сообщение о результате и список подписчиков.

## Черновые состояния

- загрузка списка;
- пустой список;
- отправка формы;
- успешное добавление;
- ошибка с текстом от сервера.

## Первоначальные допущения команды UI

- Любая успешная отправка возвращает HTTP `200`.
- Ответ имеет форму `{ "name": "Ann" }`.
- Дубликат показывается как ошибка.
- Ограничение длины имени не определено.

Эти пункты нельзя было передавать в код до сверки со спецификацией логики.
