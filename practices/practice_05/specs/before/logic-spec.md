# Команда 2 — logic spec до согласования

## Намерение

Логика хранит уникальные имена, выдаёт список и сохраняет данные между перезапусками.

## Первоначальные допущения команды логики

- Создание возвращает HTTP `201`, повтор — `200` и не считается ошибкой.
- Ответ имеет форму `{ "subscriber": { "name": "Ann" }, "created": true }`.
- Пробелы нормализуются, регистр не влияет на уникальность.
- Максимальная длина — 40 символов.
- Ошибка имеет стабильные `code` и `message`.

Расхождения с UI-черновиком разрешены в `../agreement.md` до реализации.
