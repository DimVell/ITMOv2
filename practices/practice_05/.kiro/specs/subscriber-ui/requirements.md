# Requirements: subscriber UI

## User story

Как пользователь Notify Mini, я хочу добавить подписчика и сразу увидеть итоговый список,
чтобы управлять подпиской без прямого вызова Python-кода.

## Acceptance criteria

1. WHEN страница открыта, THE UI SHALL запросить `GET /api/subscribers`, показать каждое
   имя и фактическое количество элементов.
2. IF список пуст, THE UI SHALL показать понятное пустое состояние.
3. WHEN пользователь отправляет имя, THE UI SHALL передать JSON в `POST /api/subscribers`
   и заблокировать повторную отправку до ответа.
4. WHEN API возвращает `201`, THE UI SHALL сообщить о добавлении и обновить список.
5. WHEN API возвращает `200` с `created=false`, THE UI SHALL сообщить о существующем
   подписчике без представления результата как ошибки.
6. IF API возвращает ошибку, THE UI SHALL показать `error.message` в `aria-live`-области и
   сохранить возможность повторить ввод.
7. THE UI SHALL оставаться пригодным для ширины 320 px и иметь связанные `label`, status и
   видимый focus.

## Out of scope

Удаление, редактирование, авторизация, клиентская сортировка и собственные правила
нормализации.
