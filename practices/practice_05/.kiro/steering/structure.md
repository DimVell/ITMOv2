# Structure steering

```text
app/                 реализация домена, HTTP и статического UI
tests/               unit, API и сквозная проверка
scripts/demo.py      короткий сценарий приёмки
.kiro/specs/         две согласованные Kiro-спеки
specs/before/        независимые черновики двух команд до согласования
specs/               общий контракт и протокол решений
```

Backend не знает о DOM, UI не повторяет правила нормализации и опирается на ответы API.
