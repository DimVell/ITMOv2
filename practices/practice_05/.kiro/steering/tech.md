# Technology steering

- Python 3.10+ standard library: HTTP server, JSON persistence and `unittest`.
- Vanilla HTML, CSS and JavaScript; сборщик и внешние runtime-зависимости не нужны.
- Публичный контракт — JSON over HTTP, документирован в `specs/common-contract.md`.
- Проверка — `make test`; короткое воспроизводимое демо — `make demo`.
- Исходный demo в `practice_03/lab/demo` используется только как источник старого поведения
  и не изменяется.
