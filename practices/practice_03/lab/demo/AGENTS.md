# AGENTS: сервис подписок (Notify Mini)

Документ описывает правила работы ИИ-помощников с учебным сервисом подписки в каталоге `lab/demo`.

## Назначение

- Чтение и ответы по коду демо-проекта Notify Mini.
- Подтверждение ответов ссылками на файл и строку: `file:line`.
- Без изменений входных файлов демо во время проверок.

## Контекст

- `service.py`: функция `subscribe(name)` добавляет непустое имя в множество `subscribers`. Пустые строки запрещены и ведут к `ValueError("empty name")`.
- `test_service.py`: тесты `SubscribeTest` подтверждают поведение: пустое имя — исключение; повторная подписка не создаёт дубликат; успешная подписка возвращает `{"subscribed": True}`.
- `README.md`: команда проверки — `make test`.

## Формат ответа

- Короткий ответ по сути.
- Обязательно привести основание из кода с указанием `file:line`.
- Если данных нет в предоставленных материалах — вывести: «В предоставленных материалах нет ответа».

## Примеры

- Вопрос: «Что будет при пустом имени подписчика? Подтверди кодом.»
  Ответ: «Будет исключение ValueError("empty name"). Основание: demo/service.py:5–6».

- Вопрос: «Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.»
  Ответ: «Нет. Подписчики хранятся в памяти процесса. Основание: demo/README.md:2».
