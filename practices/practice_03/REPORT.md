Ollama или LM Studio / OpenCode / Python, версии:

Модель, разработчик, семейство, тег и ID:
- qwen3.5:4b, семейство qwen35, параметров ~4.7B, ID 2a654d98e6fb

Формат, квантизация, лицензия, источник:
- gguf, quant Q4_K_M, лицензия Apache-2.0, источник ollama pull qwen3.5:4b
