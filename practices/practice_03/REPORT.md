## Окружение

ОС / CPU / GPU / RAM / VRAM / свободный диск:
- macOS (darwin), MacBook Air M4; унифицированная память 24 GB; дискретной GPU нет; свободный диск: не зафиксировано

Ollama или LM Studio / OpenCode / Python, версии:
- Ollama: клиент 0.34.4; сервер запущен локально (OLLAMA_NO_CLOUD=1)
- OpenCode: 1.18.32
- Python: 3.14.7

Модель, разработчик, семейство, тег и ID:
- qwen3.5:4b, семейство qwen35, параметров ~4.7B, ID 2a654d98e6fb

Формат, квантизация, лицензия, источник:
- gguf, quant Q4_K_M, лицензия Apache-2.0, источник ollama pull qwen3.5:4b

Фактический контекст, размещение CPU/GPU:
- itmo-local: контекст 4096 (Modelfile), запуск CPU (Apple Silicon unified memory)
- itmo-agent: контекст 65536 (Modelfile.agent); фактически по карточке модели доступно до 262144; размещение: 100% GPU (ollama ps)

Почему выбрана эта конфигурация:
- соответствует требованиям практики для 24 GB RAM; баланс качества/скорости; размер весов ~3.4 GB

## Воспроизведение

Команды и файлы конфигурации:
```
ollama --version
ollama pull qwen3.5:4b
OLLAMA_NO_CLOUD=1 ollama run qwen3.5:4b "Объясни разницу между моделью и сервером двумя предложениями"
curl --fail http://localhost:11434/api/tags
ollama list
ollama show qwen3.5:4b
make -C practices/practice_03/lab install
make -C practices/practice_03/lab test
```

Подтверждение локального endpoint и скачанных весов:
- API: {"models":[{"name":"qwen3.5:4b", ...}]}
- ollama list: модель присутствует, SIZE ~3.4 GB, ID 2a654d98e6fb
- show: format gguf, family qwen35, quant Q4_K_M, context 262144

Проверка без сети после подготовки:
- OLLAMA_NO_CLOUD=1 установлен на серверный процесс; повторная проверка без интернета не выполнена (нужно перезапуском и офлайн-режимом)

## Локальная модель в OpenCode

Подготовка профиля 64k:
- Создано: `ollama create itmo-agent -f Modelfile.agent`; проверено `ollama show itmo-agent` (num_ctx=65536), `ollama run itmo-agent` ответил «READY», `ollama ps` показал размещение 100% GPU.

Проверка OpenCode в demo:
- Команда: `opencode run --dir demo --agent local-guide --model ollama/itmo-agent --format json "Прочитай README.md инструментом read. Назови команду тестирования со ссылкой на файл" > results/read-check.jsonl`
- Результат: процесс завис и был прерван по таймауту (2 и 5 минут); файл результатов пустой. Причина требует диагностики (проверить global opencode config, отключение внешних подключений, а также доступ к локальному endpoint http://localhost:11434/v1).
