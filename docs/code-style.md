# Code Style Guide (Repo-wide)

Цель: единые правила для Python-кода репозитория и автоматическая проверка в CI при push/PR.

Поддерживаем минимальный, быстрый стек — Ruff (линт и форматирование) без внешних зависимостей.

## Базовые правила

- Python 3.10+.
- Стандартная библиотека по умолчанию; внешние зависимости только при явной необходимости.
- Имена: snake_case для функций/переменных, PascalCase для классов.
- Длина строки: ≤ 100 символов.
- Импорты: stdlib → third-party → local, внутри групп — алфавитный порядок.
- Явные исключения с понятными сообщениями.
- Докстроки по необходимости; комментарии только там, где поведение неочевидно.

## Инструменты

- Ruff как единственный инструмент для линта и форматирования.
- Конфигурация — `pyproject.toml` (разделы `tool.ruff` и `tool.ruff.format`).

Локальный запуск:

```
pip install ruff
ruff format .
ruff check .
```

## CI (GitHub Actions)

- Workflow `.github/workflows/code-style.yml` запускает проверки Ruff на push и pull_request.
- Форматирование проверяется в режиме `--check` (без перезаписи файлов).

## Исключения и каталоги

- Автогенерируемые и служебные каталоги исключены: `practices/practice_03/lab/results/**`, `.opencode/**`, `.github/**`, `node_modules/**`.

## Принятие изменений

- Перед PR: `ruff format` и `ruff check` должны быть зелёными.
- Малые, атомарные изменения; понятные сообщения коммитов; без секретов и путей локального окружения.
